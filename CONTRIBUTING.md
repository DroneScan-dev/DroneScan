# Contributing to DroneScan

Thanks for your interest in contributing! This project welcomes contributions of all sizes — typo fixes, new chapters, code modules, and bug reports.

## How to Contribute

1. **Fork** the repository
2. **Create a branch**: `git checkout -b feat/your-contribution`
3. **Make your changes** (docs, code, or both)
4. **Test** your changes locally where applicable
5. **Commit** using a clear message: `git commit -m "feat: add zone alert cooldown logic"`
6. **Push**: `git push origin feat/your-contribution`
7. **Open a Pull Request** describing what you changed and why

## Areas to Contribute

| Area | Examples |
|---|---|
| 📖 Documentation | Fill in chapter skeletons, fix typos, add diagrams |
| 💻 Code | Implement TODOs in `code/`, add tests, improve performance |
| 🐛 Bug fixes | See open issues labeled `bug` |
| 🌍 Translation | Translate docs into other languages |
| 🎁 New modules | Propose new detection/tracking/alerting features via an issue first |

## Style Guidelines

- Python code: formatted with `black`, linted with `ruff`
- Docs: Markdown, one chapter per file under `docs/chapterN/`
- Keep PRs focused — one logical change per PR
