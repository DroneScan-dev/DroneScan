# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| main branch | ✅ |
| older tags | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in DroneScan, please **do not** open a public issue.

Instead, email **security@dronescan.io** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within 72 hours and will work with you on a coordinated disclosure timeline.

## Scope

This applies to the code in this repository (detection, tracking, API, and edge-deployment modules). It does not cover third-party dependencies, which should be reported to their respective maintainers.
