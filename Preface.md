# Preface

## Why this repo exists

DroneScan started as a simple question: drones can record everything, but who turns that footage into a decision in under a second, without a cloud connection? This repository documents the answer step by step — from detection theory to a deployable edge-AI system.

## How to use this repo

- Read the chapters in `docs/` in order if you're learning the system from scratch.
- Jump straight to `code/` if you want working, runnable modules for detection, tracking, alerting, or edge deployment.
- Use the chapter that matches your current problem if you're integrating DroneScan into an existing product.
